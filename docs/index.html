macOS Native App

Google Keep,
natively on your Mac.

Fast, offline-first notes with liquid glass materials, system Spotlight search, and menu bar quick capture. Built with Swift & SwiftUI.

Download for Mac (.dmg) View Source Code

Requires macOS 14.0 or newer • Apple Silicon & Intel

Designed for macOS speed

Zero bloat, instant launch times, and full offline fidelity.

⚡

Offline-First Architecture

Instant SQLite local cache. Read, write, and search your notes with zero network latency. Changes synchronize transparently in the background.

🪟

Native Liquid Glass UI

Built purely in SwiftUI with a 3-column split layout, transluscent sidebars, fluid animations, and automatic system dark mode matching.

📌

Menu Bar Quick Capture

Draft quick thoughts from any application using the menu bar icon. Easily toggle the icon on or off in app preferences anytime.

🔍

CoreSpotlight Integration

Press ⌘ Space to search notes from anywhere in macOS. Jump directly to matching notes with instant deep-linking.

📝

Markdown & Checklists

Toggle interactive checklist items with drag-to-reorder, format markdown previews, organize tags, and apply note colors.

🔒

Private & Independent

Authentication happens directly via Google. Notes are stored strictly on your device. Zero telemetry, trackers, or middleman servers.
