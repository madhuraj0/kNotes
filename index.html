kNotes

Fast, native macOS notes app for Google Keep.

Download DMG View on GitHub

macOS 14.0+ • Apple Silicon & Intel • GNU GPLv3 License

Features

⚡ Offline-First

Instant local cache with automatic background sync to Google Keep.

🪟 Native macOS

Built with Swift & SwiftUI with a fluid 3-column layout and liquid glass materials.

📌 Menu Bar Capture

Quick note taking from anywhere with customizable menu bar visibility.

🔍 Spotlight Search

Search all notes system-wide with ⌘ Space via CoreSpotlight.

📝 Rich Content

Interactive checklists, markdown preview, tags, and note colors.

🔒 Private & Secure

Direct Google sign-in. Local token storage with zero tracking.
